# DT企业智能管理系统架构图合集

> 本文档集中展示 DT 企业智能管理系统的核心架构图、业务链路图、部署图、权限流程图、AI 能力图和数据关系图。
> 图表使用 Mermaid 编写，可在支持 Mermaid 的 Markdown 查看器中直接渲染。
> 如果只想快速理解整个项目，建议优先阅读本文档。

***

## 4. 主请求链路图

```mermaid
sequenceDiagram
    participant User as 用户浏览器
    participant Home as home/base.html 主框架
    participant JS as static/js/home.js
    participant Router as dtcall.urls
    participant Middleware as 中间件
    participant View as 业务视图
    participant Service as 业务服务
    participant Model as ORM模型
    participant DB as 数据库
    participant Template as 业务模板

    User->>Home: 登录后进入后台主界面
    User->>JS: 点击左侧菜单
    JS->>Home: 创建或切换 LayUI Tab
    Home->>Router: iframe 请求业务 URL
    Router->>Middleware: 路由分发前后执行中间件
    Middleware->>View: 权限通过后进入视图
    View->>Service: 调用业务服务
    Service->>Model: 查询或修改模型
    Model->>DB: 执行 SQL
    DB-->>Model: 返回数据
    Model-->>Service: 返回模型对象
    Service-->>View: 返回业务结果
    View->>Template: 渲染页面
    Template-->>Home: iframe 显示页面
```

## 22. 读图结论

通过以上图可以快速得到以下结论：

1. 系统是 Django 单体模块化架构，不是微服务，也不是前后端分离工程。
2. `user.Admin` 是身份与权限核心，几乎所有业务模型都直接或间接关联它。
3. `department.Department` 是多数业务使用的组织维度核心。
4. 客户、合同、项目、财务构成经营交付链路。
5. 产品、BOM、工艺、生产计划、生产任务、完工入库、库存构成制造供应链链路。
6. 审批、消息、网盘、个人办公、OA 是横向协同能力。
7. AI 模块不是单一聊天工具，而是横向智能能力平台，支撑多个业务域的分析、预测、摘要、识别和工作流编排。
8. 部署上推荐 PostgreSQL + Redis + Gunicorn + Docker Compose，AI Orchestrator 作为侧车进程运行。
