# Supply Chain Detail Workbench Implementation Plan

**Goal:** 为预测、委外、PR、核价和打样提供统一详情工作台，并将列表改造成高效待办入口。

**Architecture:** 复用现有模型和动作接口，新增五个只读详情视图与模板；动作成功后重定向详情页。列表模板只保留摘要和详情入口，不新增重复业务服务。

**Tech Stack:** Django、Django ORM、Layui、现有供应链CSS、Django TestCase、Playwright。

## Tasks

1. 先增加五类详情路由与页面响应测试，验证当前缺失。
2. 实现详情视图上下文、来源跳转和事件时间线。
3. 创建统一风格的五个详情模板及响应式样式。
4. 将现有动作成功重定向到详情页并覆盖测试。
5. 精简五类列表操作列，仅保留查看处理入口。
6. 运行供应链测试、系统检查和浏览器桌面/移动验收。
7. 审查无旧表单、死路由和重复逻辑后中文提交。
